# 【科普】手麻危害大，不一定是颈椎病

> 更新时间：2026-09-16 (UTC+8)

****

    随着生活方式的改变，低头族，办公族越来越多，经常出现手部麻木不适，手一麻大家首先就想到了颈椎病，可是很多并不是颈椎病，日常生活中出现手指无力，桡侧3个半手指麻木疼痛，手指不灵活，时间长还会出现手部肌肉萎缩，如果出现以上症状，您可能患上了”腕管综合征”。

// **什么是腕管综合征**
腕管综合征(Carpal Tunnel Syndrome)是最常见的周围神经卡压性疾病，是正中神经在腕部腕管内受卡压引起的。腕管综合征可能由很多原因引起，比如腕骨骨折；腕部肿物；外伤、感染、出血；风湿、类风湿、内分泌紊乱等，其中较常见的原因是腕部过度劳累。腕管中的空间是固定的，手指用的多，肌腱活动频繁，就会引起局部滑膜水肿，增厚，正中神经卡压缺血，手指麻木，严重会出现肌肉萎缩，没有力气。例如现代人长时间使用鼠标，因此此类人群出现的腕管综合征就是我们俗称的“鼠标手”。

**/****/****腕管综合征的临床表现**

最常见的症状，腕部、手掌桡侧、桡侧3个半手指有蚁行感、麻木、肿胀、疼痛，夜间或清晨明显，可延伸到肘、肩部，活动及甩手后减轻。肌力减退和肌肉萎缩：拇外展、屈曲和对掌肌力减弱，大鱼际肌肉出现萎缩。

**/****/****腕管综合征的危害**

正中神经长期受压，神经缺血缺氧引起麻木、疼痛、蚁走感等依次感觉，最终造成神经变性，变成不可逆性损伤。表现为大鱼际肌严重萎缩，形成猿手畸形，手部正中神经支配区感觉完全丧失，皮肤发干、发凉、色泽改变，甚至溃疡形成。

**/****/****腕管综合征如何治疗**

1、非手术治疗：适合于症状轻、病程短、全身情况不允许手术的患者。

1）外固定：症状明显者，用石膏托或夹板固定腕关节于轻度背伸位1-2周。

2）服用消炎止痛药物。

3）休息：在症状不太严重时，建议您多休息，降低腕部的活动力度。

4）腕管封闭：用利多卡因和类固醇制剂作腕管内注射，每周一次，3-4次一疗程。

5）中医理疗。

2、手术治疗：非手术治疗2周无效，腕管内占位性病变的，症状较重的，有大鱼际肌萎缩者，应及早进行手术治疗，解除对正中神经的压迫。手术可获得满意效果。

**/****/ 如何预防**
避免上肢长时间处于固定、机械而频繁的工作状态下，需定期活动肢体，做一些握拳、捏指等方式手指手腕的动作，避免关节过度劳损。
